## Project Template Guide

### Status Options
- **Not Started**: Project defined but not begun
- **Active**: Currently being worked on
- **On Hold**: Paused for some reason
- **Completed**: Successfully finished

### Status Indicators
Use emoji indicators for quick visual scanning:
- 📚 Research/Learning phase
- 🔍 Investigation/Discovery
- 🔄 In Progress
- ⏸️ Paused/Blocked
- ✅ Completed
- ❌ Cancelled

### Success Criteria
Make success criteria specific and measurable:
- ✅ Good: "Run first experiment and see results in analytics platform"
- ❌ Bad: "Improve experimentation"

### Implementation Phases
Break work into digestible phases:
1. Understanding/Research
2. Planning/Design
3. Implementation
4. Testing/Validation
5. Documentation/Handoff

### Linking
Always link back to:
- Meeting summaries where discussed
- Goals documents
- Related projects
- Action items tracking

### Maintenance
Update project files:
- After each related meeting
- When completing major milestones
- When status changes
- When new risks/learnings emerge
